2. Governing Field Equations & Tensions

Existing Gaia DR3 wide-binary analyses diverge sharply between Newtonian consistency (γrel = 1.000; Pittordis & Sutherland 2023; Banik et al. 2024) and canonical MOND boosts (γrel ≈ 1.38–1.40; Chae 2023, 2024; Hernandez 2023). Both equations tested here occupy an intermediate boost window with zero free parameters fitted to stellar binaries:

  • Model v0 (Additive Cubic-Gradient Scalar): −∇·(|∇Ψ|∇Ψ / ac) = 4πGρ with gtot = gN + gΨ,self and ac = 1.9 × 10−11 m s−2 fixed globally from 171 SPARC rotation curves.
  • Model v1.3 (Exponential Poisson AQUAL): −∇·[μ(|∇Φ|/a0)∇Φ] = 4πGρ using Milgrom's thermodynamic function μ(x) = 1 − e−x at canonical a0 = 1.20 × 10−10 m s−2.
Documented Pre-DR4 Empirical Tensions: Rather than cherry-picking favourable galaxies, Table 3 of the Zenodo note explicitly logs that v0 underpredicts velocity dispersions in undisturbed Milky Way dwarf spheroidals (Fornax γσ = 0.735, Leo I γσ = 0.707, Leo II γσ = 0.609). Model v1.3 resolves Fornax (γσ = 1.028), Leo I (γσ = 0.967), and H I gas-rich SPARC dwarfs (median bias −0.0042 dex), at the cost of higher RMS scatter in massive high-surface-brightness spirals (0.1556 dex vs 0.1391 dex for RAR+EFE).

4. Pre-Registered Statistical Decision Boundaries (Zero Post-Hoc Tuning)

During Gaia DR4 ingestion (strict primary cut: heliocentric distance d < 200 pc, chance-alignment R < 0.01, parallax SNR > 10, RUWE < 1.2 on both components, main-sequence filter), the measured ratio γrel(10–30 kAU) is masked by a cryptographically seeded random additive offset while unresolved hierarchical triple modelling (ftriple ∈ {0, 0.20, 0.35, 0.50} under thermal eccentricity f(e) = 2e) and hemisphere systematics splits are logged. Unblinding occurs once. Both Estimator A (matched Keplerian Monte Carlo) and Estimator B (forward triple population model) must agree within 1σ.
